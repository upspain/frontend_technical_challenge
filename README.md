# Frontend Technical Challenge

This repository contains the specification for a junior frontend developer technical challenge using Angular.

Read the complete assignment in [`challenge.md`](./challenge.md).

## Expected Response

Please submit your solution as a Git repository containing:

- The complete source code
- A working application
- A clear `README.md` with setup, build, and Docker instructions
- Relevant technical decisions and future improvements
- The Git history created during development

Share the repository URL with the reviewer. A public repository is preferred. If the repository must be private, grant access to the reviewer before submission.

The reviewer should be able to clone the repository and run the application by following the documented instructions.

## Technical Freedom

You may use any tools and resources that help you complete the challenge, including AI assistants, documentation, tutorials, third-party libraries, mock data, and development tools.

There is no penalty for using these resources. During the review, you may be asked to explain your implementation, choices, and how the tools helped you.

## Docker Requirement

Dockerization is part of the challenge. Include the necessary Docker files and document commands for:

- Building the image
- Running the container
- Accessing the application locally

The solution should run without requiring the reviewer to install Angular or other project dependencies on the host, apart from Git and Docker.

## Initiative Is Welcome

The requirements in [`challenge.md`](./challenge.md) are the minimum expected scope. Additional improvements and initiatives are welcome when they are useful and well-prioritized.

Examples include accessibility improvements, loading and empty states, tests, filtering, sorting, visual polish, or better error feedback. Do not feel pressured to implement everything; explain what you chose and what you would do next.

## Suggested README Sections In Your Submission

Your application README should include:

1. Project overview
2. Prerequisites
3. Local setup and development commands
4. Production build commands
5. Docker build and run commands
6. Technical decisions
7. Implemented improvements
8. Future improvements
9. AI and external tools used, if relevant
